# ⚽ Pelada de Segunda

Projeto para organização, sorteio de times e gestão da pelada semanal.

## 🎯 Objetivo
Facilitar a administração do futebol com a galera:
- Lista de presença e confirmação de jogadores
- Sorteio equilibrado de times
- Controle de gols, artilharia e pontuação
- Gestão de mensalidades e pagamentos da quadra
